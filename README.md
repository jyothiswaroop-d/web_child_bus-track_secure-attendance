# web_child_bus-track_secure-attendance
Abstract:
Modern school transportation depends on safety, accurate attendance system, and effective communication between home and school. However, many existing systems, even those with real-time tracking, lack reliable mechanisms to monitor student attendance. This paper proposes an end-to-end integrated solution to improve child safety during transportation. The system integrates IoT hardware components, including an ESP32 microcontroller connected to a PN532 NFC V3 module, IR sensors, and a NEO-6M GPS module. integrated with a software(React.js) web interface for real-time monitoring. Two IR sensors placed sequentially at the bus door detect student movement, where IR1 → IR2 indicates boarding and IR2 → IR1 indicates exit. When a boarding event is detected, a 5-second NFC scanning window opens for the student to tap the NFC card, and the attendance data is securely stored in the MongoDB cloud backend through RESTful APIs. The record is stored only when a valid NFC scan corresponds to the detected IR entry event, enabling dual-layer verification of physical presence and NFC-based identity authentication. Multiple NFC scans during the same entry event are treated as proxy attempts, and an alert email is automatically sent to the administrator using Nodemailer. Meanwhile, the NEO-6M GPS module continuously sends GPS coordinates to the cloud backend, allowing bus location and student activity to be monitored through a React.js web interface; during login users select the user type (Administrator or Parent), parents can track bus location and their child’s attendance records, while management can monitor all buses and view daily student attendance for morning and evening sessions. The system is cost-efficient and fully integrated. As a result, attendance data appeared on the web interface within about 3 seconds after scanning, proxy alerts were sent to administrators within about 2 seconds via email, and GPS positioning accuracy was approximately 5–10 meters.
